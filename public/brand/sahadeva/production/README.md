# Sahadeva production asset pack

This directory contains reproducible distribution assets generated from the canonical Sahadeva SVG identity.

Run `node scripts/generate-sahadeva-production-assets.mjs` after changing a brand master. `registry.json` records every file's dimensions, format, purpose and approval status.

## Rules

- Use `icons/app-store-1024.png` for the Apple store master and `icons/play-store-512.png` for Google Play.
- Use the SVG social and press files as editable masters; PNG files are delivery exports.
- Do not recolor the mark with fate-signalling red or green.
- Do not use a Graha or devotional illustration as the Sahadeva brand mark.
- Devotional artwork is editorial content and remains pending qualified cultural review.
- Store screenshots must be captured from real builds; this pack deliberately does not fabricate product UI screenshots.
