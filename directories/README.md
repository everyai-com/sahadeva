# directories/ - submit Sahadeva everywhere

Packets to list the Sahadeva MCP engine (`https://sahadeva.magicteams.ai/mcp`,
54 annotated tools) in AI directories and MCP registries.

- `chatgpt-plugin/` - ChatGPT plugin package (plugin.json, mcp.json, skill,
  icons) + TEST_CASES.md, PROMPTS.md, SUBMISSION.md checklist.
- `claude/SUBMISSION.md` - Claude Connectors Directory portal values.
- `muse/SUBMISSION.md` - Meta Muse directory form values.
- `server.json` - official MCP registry manifest (`mcp-publisher publish`
  from this dir).
- `DISTRIBUTION.md` - submit-everywhere runbook (Tier 1-4 order).
- `GROWTH.md` - first-100-users plan. `VOLUME.md` - demand research.

Source of truth for the factory process lives in the connector-saas
workspace; this subdir is the shippable per-product packet.
